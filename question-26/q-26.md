CronJob with Secrets and ConfigMaps (12 Minutes)
This combines scheduling with configuration management.

Create a Secret named db-pass with password=qwerty.

Create a ConfigMap named db-config with db_name=orders.

Create a CronJob named nightly-cleanup that runs every night at 2:00 AM.

The job should use mysql:5.7 and execute: mysql -u root -p$DB_PASSWORD $DB_NAME -e "DELETE FROM logs;".

Pass the Secret password as an env var DB_PASSWORD and the ConfigMap db_name as DB_NAME.

Verification: Check k get cronjob to see the schedule is 0 2 * * *.
