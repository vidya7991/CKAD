StatefulSet with Headless Service (12 Minutes)
StatefulSets require a "Headless Service" to maintain network identity. This is a common exam "gotcha."

Create a Headless Service named db-connectivity in the default namespace with clusterIP: None on port 27017.

Create a StatefulSet named mongodb using image mongo:4.2.

Set serviceName: "db-connectivity".

Define a volumeClaimTemplate named data-storage with ReadWriteOnce, 1Gi storage, and mount it at /data/db.

Verification: Verify that the Pods are named sequentially (mongodb-0, mongodb-1) and that the service shows no ClusterIP.
