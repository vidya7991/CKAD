🧩 Question 2: Deployment Rollout and Rollback
Task:
Create a Deployment named web-deploy with:
Image: nginx:1.19
Replicas: 3
Labels: app=web
Expose the deployment as a service on port 80.
Update the image to nginx:1.21 and confirm rollout status.
Perform a rollback to the previous version.


STEPS:
k create deploy web-deploy --image=nginx:1.19 --replicas=3 --dry-run=client -o yaml > web-deploy.yaml

k get deploy

k describe deployment/web-deploy

updated labels and port and to apply --> k apply -f web-deploy.yaml 

kubectl set image deployment/web-deploy nginx=nginx:1.21

kubectl rollout status deployment/web-deploy

kubectl rollout history deployment/web-deploy

kubectl rollout undo deployment/web-deploy
