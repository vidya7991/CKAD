Multi-Container Pod: Sidecar Pattern (12 Minutes)
This tests your ability to share data between containers using a shared volume.

Create a Pod named web-server in the default namespace.

Container 1 (Main): Name nginx-container, image nginx. Mount a volume named shared-data at /usr/share/nginx/html.

Container 2 (Sidecar): Name adapter-container, image busybox. Mount the same volume shared-data at /data.

Action: The sidecar should run a command: ["/bin/sh", "-c", "while true; do date > /data/index.html; sleep 10; done"].

Verification: Exec into the nginx-container and run curl localhost:80. It should return the date string generated by the sidecar.
