DaemonSet with Node Affinity (12 Minutes)
DaemonSets are a key part of the CKAD syllabus, often used for logging or monitoring agents that must run on every node.

Create a DaemonSet named logger-agent in the kube-system namespace.

Use the image fluentd:latest.

The Pods should be configured with a Resource Request of 100m CPU and 200Mi Memory.

Ensure the DaemonSet only runs on nodes with the label disktype=ssd. (If no nodes have this label in your lab, the pods will stay pending—this is expected behavior for the test).

Verification: Run k get ds -n kube-system and check the "Desired" count vs. "Available" count.
