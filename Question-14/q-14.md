CronJob and ConfigMap Integration (12 Minutes)
This question focuses on scheduling and using a ConfigMap to define job execution parameters.

Ensure you are working in the default namespace.

Create a ConfigMap named job-params with a key EXEC_COMMAND and value /bin/sh,-c,date > /tmp/last_run.txt.

Create a CronJob named scheduled-task that runs every hour (0 * * * *).

The job should use the image busybox.

Configure the job's container command to use the value of the EXEC_COMMAND key from the job-params ConfigMap (Hint: Use command and read the command from the ConfigMap).

Configure the CronJob to suspend future runs by setting the suspend field to true.

Verification: Describe the CronJob and confirm the schedule, image, and the suspend: True setting.
