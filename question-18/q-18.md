🧩 Question 1: Pod with ConfigMap, Secret, and Multiple Containers

Task:

Create a ConfigMap named app-config with key APP_MODE=production.

Create a Secret named db-secret with key DB_PASSWORD=mydbpass.

Create a Pod named multi-pod with:

Two containers:

frontend using image nginx:latest

backend using image busybox:latest that runs sleep 3600

The backend container should:

Mount /etc/config from the app-config

Mount /etc/secret from the db-secret

Have environment variables populated from both ConfigMap and Secret

Expose port 80 on the frontend container.




# Verification Steps
kubectl exec multi-pod -c backend -- printenv | grep APP_MODE
kubectl exec multi-pod -c backend -- printenv | grep DB_PASSWORD

# create configMap --> k create cm app-config --from-literal=APP_MODE=production
# create secret --> k create secret generic db-secret --from-literal=DB_PASSWORD=mydbpass
# to create pod --> k apply -f multi-pod.yaml
# to check pod --> k get po
# to describe pod --> k describe multi-pod-1
# to exec to pod --> kubectl exec multi-pod-1 -c backend -i -t -- /bin/sh
# to check env variables --> env
# to check whether the value exit at path --> cd /etc/config
# to check the value --> cat the env variable (cat APP_MODE)
