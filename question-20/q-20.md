🧩 Question 3: CronJob and StatefulSet

Task:
Create a CronJob named db-backup that runs every 5 minutes:
Image: busybox
Command: ["/bin/sh", "-c", "echo Backup done at $(date) >> /backup/backup.log"]
Mount an emptyDir volume at /backup.

Create a StatefulSet named mysql-db with:
Image: mysql:5.7
Replicas: 2
VolumeClaimTemplate requesting 1Gi storage
Env vars: MYSQL_ROOT_PASSWORD=root123
Service name: mysql-svc
Headless service for stable network identity.


# Create a cron job with a command
kubectl create cronjob db-backup --image=busybox --schedule="*/5 * * * *" 

Add the command and then run --> k apply -f cron-job.yaml

To check logs, run below commands
kubectl get jobs
kubectl logs job/<job-name>
